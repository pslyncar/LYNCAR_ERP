# Equipamentos

## Campos previstos

- Cliente vinculado.
- Nome do computador.
- Sistema operacional.
- Processador.
- Memoria RAM.
- Armazenamento.
- Status do equipamento.
- Observacoes tecnicas.
- Data de cadastro.

## Relacao com monitoramento

Cada maquina monitorada deve estar vinculada a um cliente.
