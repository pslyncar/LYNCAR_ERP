# PapezzoSync Admin App

Aplicativo administrativo em Flutter/Dart.

## Objetivo

Este app sera usado por administradores, tecnicos, vendedores e colaboradores da PapezzoSync.

Primeiras telas previstas:

- Login
- Dashboard
- Menu conforme permissoes do usuario
- Clientes
- Equipamentos
- Chamados
- Ordens de servico
- Produtos, pecas e servicos
- Usuarios e permissoes
